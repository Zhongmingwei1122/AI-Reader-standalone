# AI Pocket Reader · 官方独立站（简易版）

AI Pocket Reader 的品牌官网、产品展示、AI 功能演示、用户中心与商店原型。

当前版本：**可交互静态站点**，无需构建，落地页与核心流程均已实现。完整需求见 [PRD.md](PRD.md)。

## 快速开始

直接打开：

[index.html](index.html)

或在项目目录启动一个静态服务器：

```powershell
python -m http.server 8001
```

然后访问 http://localhost:8001/

## 已实现的交互

- **购物车**：产品配置与商店加购、数量增减、移除、localStorage 持久化、结账摘要。
- **产品配置**：颜色与套装切换，价格联动；立即购买进入结账。
- **AI 演示**：5 个功能标签切换；问答 chips 切换答案；知识库示例搜索。
- **账户**：7 个模块切换；演示数据、设备同步状态与订阅卡。
- **结账**：表单校验、演示订单号、成功后清空购物车。
- **支持**：FAQ 关键词过滤、折叠问答、联系/等待名单表单反馈。
- **导航**：响应式移动菜单、公告关闭、购物车抽屉、键盘 Escape 关闭。

## 设计方向

- **Ink & Paper**：纸色底、墨色字、单一信号红。
- 宋体标题 + 无衬线正文，编辑式栅格与大量留白。
- 产品视觉复用设备端 480×800 原型截图，包裹在墨水屏设备边框中。
- 无外部字体、无构建依赖、无图片 CDN。

## 演示限制

- 所有价格、库存、参数、评分、评价均为演示数据；页面顶部公告已明确说明。
- 不连接真实支付、物流、账户或 AI 服务。
- 购物车保存在浏览器 localStorage；结账不会产生真实订单。
- 用户评价区刻意不放置虚构内容；真实反馈预留给首批用户。
- 当前为静态简易版；生产版计划使用 Astro + AstroWind，并接入 commerce、账户/设备 API 与真实 AI 演示。
